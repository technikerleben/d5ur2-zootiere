# Chaos im Zoo

[Spiel starten](index.html)

Freiwilliges Angebot für den offenen Start in Deutsch 5, ungefähr fünf Minuten pro Runde. Drei Tafeln pro Runde, ohne Zeitdruck. Für einen einzelnen Kiosk-Laptop, Maus, Touch oder Tastatur (Tab / Eingabe / Leertaste). Bei Bedarf nur eine Aufgabenart wählen. Zu zweit liest ein Kind und begründet, das andere bedient; nach jeder Tafel Rollenwechsel.

## Inhalt

- Etappe 1: Sachangaben über eine Tierart von Meinungen und Angaben zu einem einzelnen Zootier unterscheiden.
- Etappe 2: genaue, sachliche Formulierungen im Präsens wählen.
- Etappe 3: Überblick / Aussehen / Lebensraum / Nahrung zu einer kurzen Beschreibung ordnen.

Neue Spielaufgaben auf Basis der Inhaltsquellen `inhalt/interviews.json`, `inhalt/etappe1.json`, `inhalt/etappe2.json` und `inhalt/etappe3.json`. Übungstiere Fischotter, Erdmännchen und Roter Panda. Keine Prüfungsaufgaben, Nachweislösungen oder Prüfungstiere. Die kurzen Spieltexte sind keine vollständigen Musterlösungen für die Pflichtblätter. Das Spiel vergibt keine Etappenfreigabe.

## Technik

`index.html` ist das vollständige Spiel einschließlich CSS, JavaScript, Fotos und Andika-Schrift (Data-URLs). Lokal im Browser öffnen oder unter `/apps/chaos-im-zoo/` aufrufen. Keine externen Bibliotheken, Downloads oder Konten nötig. Spielstand nur im Arbeitsspeicher; Startseite/Neuladen setzt die Runde zurück. TTS nutzt die Vorlesefunktion des Browsers: Verfügbarkeit und mögliche Online-Sprachdienste hängen von Gerät, Browser und installierten Stimmen ab. Alle anderen Funktionen laufen offline.
